# AI 사무실 플러그인 (ai-office)

내 맥에 **AI 직원 15명이 일하는 게임형 사무실**을 세워 주는 Claude 플러그인이에요.
사무실 화면에서 일을 맡기고, 결재하고, 보고를 받아요.
강의자료, 강의 영상(헤이젠), 홈페이지, 아이디어 회의, 아침 일정 보고(카톡) 같은 일을 해요.

## 준비물

- **맥** 한 대 (사무실이 맥에서 돌아가요. 윈도우·휴대폰은 맥 사무실에 접속해서 써요)
- **Claude 유료 구독** + Claude 앱 (Code 탭 사용)
- (영상을 만들려면) 헤이젠 계정 · (선택) 힉스필드 · 캔바 · 구글 캘린더 · 카카오 개발자 앱

## 설치하기

맥의 Claude 앱 **Code 탭**에서 아래 두 줄을 차례로 입력하세요.

```
/plugin marketplace add agada73/ai-office-plugin
/plugin install ai-office@ai-office
```

## 사무실 세우기

설치한 뒤 Claude에게 이렇게 말하세요.

> **AI 사무실 세워 줘**

Claude가 한 단계씩 물어보면서 사무실을 세워 줘요. 로그인과 비밀번호 입력만 직접 하시면 돼요.

## 알아 두기

- 직원은 **내 Claude 구독**으로 일해요. 영상은 **내 헤이젠 크레딧**이 들어요 (결재한 뒤에만 써요).
- 내 설정과 일 기록(`data/` 폴더)은 남에게 주거나 인터넷에 올리지 마세요.
- 원래 사무실 주인의 개인 정보는 모두 빼고 만든 나눔판이에요.
- 만든 날: 2026-11-19
