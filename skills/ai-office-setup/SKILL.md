# AI 사무실 세우기

이 스킬 폴더의 `office/` 에 개인 정보를 뺀 사무실 프로그램 전체가 들어 있다.
목표: 사용자의 맥에 사무실을 세우고, 바탕화면 아이콘으로 열어 첫 일을 맡겨 보게 하는 것.

## 대화 원칙 (꼭 지킬 것)

- 사용자는 코딩을 잘 모르는 교수·교사일 수 있다. **쉬운 한국어**로, 어려운 말은 괄호로 짧게 풀고, 한 번에 한 단계씩 안내한다.
- 명령은 Claude 가 직접 실행한다. 사용자가 직접 해야 하는 것은 **로그인·비밀번호·결제·카카오/헤이젠 계정 설정**뿐이다.
- **비밀번호·키·토큰은 사용자가 직접 입력**하게 한다 (예: 사용자 터미널에서 `tools/set_passcode.py`, `tools/kakao_setup.py`). 대화창에 받아 적거나 코드에 쓰지 않는다.
- 이미 있는 폴더·파일은 **덮어쓰기 전에 꼭 물어본다.**
- 크레딧(헤이젠·힉스필드)이 드는 일은 시험이라도 사용자 허락 없이 하지 않는다.

## 순서

### 1. 컴퓨터 확인
- 맥(macOS)인지 확인한다 (`uname`). **맥이 아니면 멈추고** 이렇게 알린다: "지금은 맥 전용이에요. 윈도우·휴대폰은 맥에 세운 사무실에 접속해서 써요." 맥이 있으면 그 맥에서 다시 시작하도록 안내한다.

### 2. 사무실 폴더 놓기
- 설치 위치는 기본 `~/ai-office` (바탕화면·문서 폴더는 피한다 — 맥 보안 때문에 늘 켜 둔 서비스가 못 열 수 있음).
- 이미 있으면 덮어쓰지 말고 사용자에게 묻는다 (새로 세우기 / 그대로 두고 설정만 다시 하기).
- 이 스킬 폴더의 `office/` 를 통째로 복사한다: `cp -R "<이 스킬 폴더>/office" ~/ai-office`
- 실행 권한을 붙인다: `chmod +x ~/ai-office/*.command ~/ai-office/tools/media/*.sh`

### 3. 세우기
- `~/ai-office/처음부터_세우기_안내.md` 를 읽고 **2장(Claude가 할 일)** 을 순서대로 한다.
- 1장 4번의 질문(회사 이름, 사용자 호칭, 접속 비밀번호, 헤이젠 아바타·목소리)은 해당 단계에서 하나씩 묻는다. 모르면 기본값으로 두고 나중에 바꿀 수 있다고 알린다.
- 선택 단계(무료 영상 도구, Tailscale, 구글 드라이브, 카톡 아침 보고, 배경지식)는 **하나씩 쓸지 물어본다.** 바로 필요 없으면 건너뛴다.
- 각 단계가 끝날 때마다 무엇이 됐는지 한 줄로 알린다. 오류가 나면 오류 문구를 그대로 보여 주고 쉽게 풀어 설명한다.

### 4. 마무리
- 연습 모드로 흐름을 본 뒤 진짜 모드로 켜고, 바탕화면 아이콘으로 열어 보게 한다.
- `처음부터_세우기_안내.md` 3장의 "처음 써 볼 일" 중 크레딧이 안 드는 것(💡 아이디어 맡기기)을 하나 해 보게 한다.
- 4장 "꼭 지킬 것"을 짧게 알려 준다: `data/` 폴더는 남에게 주거나 인터넷에 올리지 않기, 돈 드는 일은 결재함에서 확인 후에만.
