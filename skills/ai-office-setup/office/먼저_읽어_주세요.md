# AI 파트너스 사무실 — 나눔 꾸러미

내 맥에서 **AI 직원 15명**이 일하는 사무실을 눈으로 보며 쓰는 프로그램이에요.
일을 맡기고, 결재하고, 보고를 받아요. 강의자료, 강의 영상(헤이젠), 홈페이지, 책 원고, 아이디어 회의 같은 일을 해요.

## 들어 있는 것

| 파일·폴더 | 내용 |
|---|---|
| `처음부터_세우기_안내.md` | **여기부터 읽으세요.** 맥에 세우는 순서 |
| `설계서_design.md` | 사무실이 어떻게 생겼고 어떻게 일하는지 |
| `설정_예시_settings.example.json` | 설정 파일 틀 (비밀번호·아바타·목소리 번호는 직접 채움) |
| `app/` | 사무실 프로그램 (서버·화면·직원 지시문) |
| `tools/` | 사무실 그림(1~3층), 아이콘 앱, 비밀번호 정하기, 맥 도구, 무료 영상 도구 |
| `사무실열기_start.command` | 두 번 누르면 사무실이 켜져요 |

## 가장 빠른 방법

1. 맥에 Claude 앱 설치 → 로그인
2. 이 폴더를 홈 폴더에 두고, Claude 앱 Code 탭에서 이 폴더 열기
3. "`처음부터_세우기_안내.md`를 읽고 내 사무실을 세워 줘"라고 말하기

## 알아 두기

- 지금은 **맥 전용**이에요. 윈도우·휴대폰은 맥 사무실에 접속해서 써요.
- 직원은 **내 Claude 구독**으로 일해요. 영상은 **내 헤이젠 크레딧**이, 짧은 AI 영상·대비 목소리는 **내 힉스필드 크레딧**이 들어요(결재 후에만).
- 영상은 크레딧을 쓰기 **전에** 사무실이 스스로 미리 점검해요(대본 짝·목소리·합치기 10초 시험).
- 원래 사무실 주인의 개인 정보(이름, 폴더, 아바타·목소리, 일 기록, 결과물, 배경지식)는 빼고 만든 나눔판이에요.
- 만든 날: 2026-11-19
