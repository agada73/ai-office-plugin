# AI 파트너스 사무실 — 설계서 (나눔판)

> 한 교수님이 쓰는 'AI 직원 사무실'을, 다른 분도 세울 수 있게 개인 정보를 빼고 정리한 설계서예요. (2026-11-19 기준)
> 사무실을 세운 뒤에는 **내 사무실에 맞게 이 설계서를 계속 고쳐 쓰세요**. 기능이 늘거나 무언가를 정하면, 같은 날 해당 장과 맨 위 "고친 기록"을 고쳐요.

## 1. 무엇을, 왜 만드나

강의자료, 영상, 홈페이지 같은 일을 Claude에게 맡길 때마다 채팅창에서 처음부터 설명하고, 결과물이 어디 있는지 기억해야 했어요. 이걸 바꾸려고 만들었어요.

**AI 파트너스 사무실**은 내 컴퓨터에서 열리는 웹 화면이에요. 그 안에 3층짜리 사무실이 보이고, **AI 직원**에게 일을 맡기면 직원이 **실제로** 파일을 만들어 보고해요. 직원은 일할수록 내 취향을 배우고(업무 수첩), 점수가 쌓이면 승진해요.

이렇게 쓰면 잘 쓰는 거예요. 아침에 사무실을 열고(휴대폰으로도) 비서의 아침 보고를 읽고, 결재함 몇 건을 처리하고, 기획실장에게 한 줄로 새 일을 맡겨요. 저녁에는 보고함에서 완성된 결과물을 확인해요.

**이런 것은 실패로 봐요**
- 화면은 예쁜데 실제 파일이 안 생기거나, 어디 저장됐는지 모를 때
- 돈(크레딧)이 드는 일을 정해 둔 한도를 넘어 내 승인 없이 할 때, 크레딧을 쓴 **뒤에야** 오류가 드러날 때
- 내 원본 파일을 덮어쓰거나 지울 때
- 화면 글에 영어가 섞이거나 어려운 말이 그대로 나올 때
- 수첩에 적은 지적을 직원이 또 되풀이할 때

## 2. 지켜야 할 조건

- **사용자**: 코딩 입문 수준이라고 생각하고 만들어요. 화면 글은 모두 쉬운 한국어로 써요. 오류가 나면 쉬운 설명과 원래 오류 글을 함께 보여 줘요.
- **실행 위치**: 늘 켜 둘 **맥** 한 대에서 돌아요. 주소는 `127.0.0.1:8840`이에요. 윈도우·휴대폰은 들어가서 써요.
- **설치 최소화**: 파이썬은 표준 라이브러리만(맥 기본 3.9). 영상 합치기는 ffmpeg. 아바타 오리기·PDF→그림은 맥 기본 기능(Swift 도구).
- **한글 안전**: 파일은 모두 UTF-8, `python3 -X utf8`로 실행. 데이터 파일은 엄격한 JSON.
- **비밀 정보**: API 키·토큰은 코드에 적지 않아요. 접속 비밀번호는 `tools/set_passcode.py`. `data/`는 깃·남에게 주지 않아요.

## 3. 화면

- **사무실 그림 (본사 1~3층)**: ZEP 같은 3/4 시점, 레고풍 블록 인형이 걸어 다니고 머리 위 말풍선에 상태가 보여요. 「본사 1층/2층/3층」 버튼으로 층을 오가요. 그림은 코드(SVG)로 그려요: `tools/build_scene.py`(1층) · `build_scene2.py`(2층) · `build_scene3.py`(3층), 색은 `tools/themes.py`.
  - 1층: 기획실·아이디어팀·개발팀 / 공용 홀 / 강의팀·영상팀·검토실, 휴게실·회의실
  - 2층: 출판팀·도서실·교육팀·라운지 / 스튜디오·🎓 강당·테라스
  - 3층: ☕ 카페·💆 안마실·비서실 / 🍽 레스토랑·회의실 2·👑 대표실(대표 인형, 누르면 결재함)
  - 쉬는 직원: 점심엔 레스토랑, 오래 쉬면 휴게실(한 곳 5명)·카페, 공부할 땐 도서실
- **현황판**: 결재 대기·보고함·작업 중 숫자, 팀별 직원 줄, 프로젝트 칸, 「+ 기획실장 새 일 맡기기」「💡 아이디어」「🗣 회의 소집」, 이 사무실이 도는 컴퓨터 이름. 10분 넘게 소식 없는 직원 표시.
- **결재함·보고함·최종본 폴더**: 결재함 = "정해 주세요", 보고함 = "다 했어요, 확인해 보세요", 최종본 폴더 = 쓸 파일만 골라 둔 곳.
- **👁 미리보기**: 결재함·보고함의 파일을 내려받지 않고 펼쳐 봐요(글·그림·PDF·영상·홈페이지). 홈페이지 html은 사진을 안에 넣어서 보여 주고, 내려받아도 사진이 깨지지 않아요.
- **빨간 오류 안내**: 그 일이 다시 돌거나 끝나면 저절로 사라져요. 새 일로 다시 하면 예전에 멈춘 일은 "다른 일로 다시 함"으로 정리돼요.
- **창**: 대화창(📎 파일 · 📁 폴더 올리기 · 끌어다 놓기 · Enter로 보내기), 일 목록·진행 타임라인, 직원 프로필 카드(점수·직급·수첩 규칙·📞 대표실로 부르기), 프로젝트 보드, 비교 결과 창, 승진 축하.
- **휴대폰 화면**: 820px 이하이면 사무실 그림이 먼저, 그 아래 현황판.

## 4. 일이 흘러가는 방식

1. 내가 **기획실장**에게 일을 말해요(파일은 📎·📁). 같은 일이 이미 있으면 먼저 알려 줘요.
2. 기획실장이 어느 **프로젝트**(주제별) 일인지 정하고, 빠진 정보를 되묻고, **계획서**를 결재함에 올려요.
3. 직원들이 순서대로 일해요. 서로 다른 일은 동시에(최대 6개). 일하는 중에도 대화창으로 말을 보낼 수 있어요.
4. **기획실장 결과 검토**: 결과물을 직접 읽고 승인 / 보완 / 처음부터 다시.
5. 보고함에 보고 → 내가 승인하거나 고쳐 달라고 해요 → 그 내용이 직원 **업무 수첩**에 쌓여요.

**결재**
- 계획서·단계 결과는 기획실장이 검토해서 자동 승인. **최종 보고는 내 결재**(영상 일·비서 아침 보고만 자동).
- 크레딧: 예상 최대치가 700 이하이고 남은 크레딧이 그 두 배 이상이면 자동 승인, 넘으면 내 결재. 실패 뒤 다시 만드는 것·힉스필드 생성은 언제나 내 결재(크레딧 결재에 대비 목소리 비용을 함께 적은 경우는 그 결재로 함께 승인).
- "나한테 보여 줘"라고 말한 일은 자동 승인하지 않아요. 되묻기와 원본 파일 변경은 언제나 내 몫.
- 설정: `data/settings.json`의 `auto_approve`

**성장**
- 업무 수첩(`data/notebooks/{직원}.md`): 내가 정한 규칙, 승인된 방식, 싫어한 것과 이유. 직원은 일하기 전에 읽어요. 프로필 카드에서 규칙을 추가·삭제.
- **직급 (점수제)**: 승인 +10, 한 번에 승인 +5 / 수정 요청 −10 / 최종 보고 반려 −15 / 대표 지적 −10(또 하면 −15). 점수와 한 번에 통과 비율을 둘 다 채워야 승진(사원→주임→대리→과장→차장→부장, 기획실장은 실장→…→부사장). **결재와는 연결하지 않아요.**
- **📚 자기계발**: 하루 한 번 쉬는 직원 2명이 웹에서 공부하고 공부노트를 남겨요(크레딧 없음).
- **🎓 교육**: "교육 담당, ○○ 교육해 줘" → 교육자료·규칙 → 내 결재 → 직원 수첩에 규칙이 들어가고 강당에 모여요.

**일 조작**: 멈춤 · 이어 하기 · 처음부터 다시 · 끝내기 · 취소 · 전체 멈춤 · 지금 상황 물어보기. Claude 이용 한도에 걸리면 풀리는 시각에, 잠깐 오류는 3분 뒤 자동으로 다시 해요.

## 6. 강의 영상 만들기

1. **강의자료**가 슬라이드 쪽마다 나레이션 대본을 써요. 원래 사무실은 한 차시 25분(공백 빼고 약 8,000자). **대본을 줄이지 않아요** — 헤이젠 한 번에 5,000자가 넘으면 여러 영상으로 나눠요.
2. **검토 담당**이 사실을 점검해요.
3. 영상용 대본 정리(`heygen_scenes.json`, 쪽마다): **숫자·연도·번호는 한글 소리대로**. 발음을 따로 정한 낱말은 `settings.heygen.pronounce`(읽을 때만 바꾸고 자막은 원래 글자).
4. **발음 확인표**를 크레딧 결재에 붙여요. 숫자가 남아 있으면 멈춰요.
5. 🔎 **미리 점검** (크레딧 쓰기 전): ① 대본 쪽 수 = 슬라이드 쪽 수, 단계 이름의 'N장/차시'가 대본·슬라이드 첫머리에 있는지 ② 목소리 한 마디 시험(목소리마다 6시간에 한 번) ③ 가짜 아바타로 슬라이드 10초 합치기. 하나라도 안 되면 "크레딧은 쓰지 않았어요"로 멈춰요.
6. **크레딧 결재**: 장(차시)마다 예상 크레딧·길이.
7. **여러 장을 한 일로 만들 때는 장마다 "대본 정리 → 영상"을 짝으로** 해요. 대본 정리는 같은 폴더를 써서, 몰아서 하면 앞 장 대본을 덮어써요. 영상 단계가 시작될 때 짝 대본이 바로 앞이 아니면 사무실이 그 대본 정리를 앞으로 옮겨 다시 해요.
8. **헤이젠**: 아바타 쪽만 아바타 영상(720p, 구석에 작게 나와서), 나머지 쪽은 목소리만 만들어 슬라이드에 입혀요(크레딧 약 10분의 1). 아바타 영상은 `engine_type = "heygen_voice"`로 만들어 목소리 쪽과 같은 소리가 나요.
   - 목소리는 사무실 전체 **1분에 15쪽까지**(헤이젠 제한의 절반). 한꺼번에 많이 부르면 계정이 막힐 수 있어요.
   - 헤이젠 목소리가 막히면(401·400 "호환 안 됨") 두 번 만에 멈추고, `voice_backup`이 있으면 **힉스필드 Seed Audio**로 내 목소리를 복제해 대신 만들어요(8쪽씩, 거절되면 1분 뒤 한 번 더). 아바타 영상까지 막히면 마음대로 바꾸지 않고 멈춰요.
9. **합치기** (`app/lecture_compose.py`, ffmpeg): 슬라이드 위에 아바타를 오려 붙여요(허리까지: `upper_body 0.80`, `avatar_height 0.46`). 자를 크기는 화면보다 커지지 않게 해요. 다시 합치기만 하면 크레딧이 들지 않아요.

## 7. 그 밖의 기능

- **최종본 폴더 ⭐**: 일이 끝나면 쓸 파일만 `최종본_final/{프로젝트}/{최종본 이름}/`에 복사(옛 것은 `_이전판/`). 폴더마다 `_어디서_왔나.txt`.
- **📚 자료실**: 올린 파일·폴더는 `자료실_library/`에도 보관돼 다음 일에서도 찾아요.
- **💡 아이디어 회의**: 자료조사 → 아이디어 → 현장 담당 → 기획실장 회의록. 크레딧 없음.
- **🗣 회의 소집**: 주제와 직원을 골라 의견을 듣고 회의록·할 일을 받아요.
- **📅 비서 아침 보고**: 매일 아침 구글 캘린더 일정 + 사무실 현황(`settings.secretary`).
- **비교 모드 ⚖**: 같은 일을 Claude와 GPT(Chrome의 ChatGPT 화면)에게 함께 맡기고 합본을 만들어요.
- **🎨 캔바 · 🎬 힉스필드**: 도구 고르기 규칙에 따라 디자인은 캔바, 짧은 AI 영상·고화질 그림은 힉스필드(늘 견적 → 내 결재 → 한 번 만들기).
- **🎞 무료 영상 도구**(크레딧 없음): Whisper 자동 자막(`tools/media/subtitles.sh`), auto-editor, Manim, Remotion(`tools/remotion_template`, `tools/media/remotion_render.sh`).
- **🧠 기획실장 배경지식**: `data/knowledge/기획실장_배경지식.md`를 계획마다 읽어요(내가 직접 적음, 남에게 주지 않음).
- **프로젝트 보드 — 주제별**: 강의 과목·시리즈·책 같은 주제로 나눠요. 이어질 일이면 기획실장이 새 주제를 만들어요.
- **⬇ 한꺼번에 받기**: 바깥 화면에서는 최종본 폴더를 zip 하나로 받아요(`/api/zip`).

## 8. 어떻게 만드나 (기술)

- **직원 = Claude Code CLI 헤드리스 실행**: 단계마다 서버가 `claude -p … --output-format stream-json`을 실행. 역할 설명 + 업무 수첩 + 이번 지시를 프롬프트로(`app/prompts.py`). 내 Claude 구독으로 돌아가요. 연습 모드(`OFFICE_FAKE=1`)는 가짜 직원.
- **커넥터**: 헤이젠·힉스필드·캔바·구글 캘린더는 Claude 앱 커넥터를 CLI 안에서 씀(키를 코드에 적지 않음).
- **서버**: 파이썬 표준 HTTP 서버(`app/server.py`), 화면은 `app/web/`(index.html + app.js + scene*.json).

- **다른 기기**: 사무실은 맥 한 곳에서만. `settings.remote=true` + 비밀번호 + Tailscale(필요하면 Funnel). 바깥 화면에서는 맥 전용 버튼을 숨겨요.
