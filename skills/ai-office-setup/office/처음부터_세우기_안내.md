# 내 AI 사무실 처음부터 세우기

> 이 꾸러미를 받으신 분께. 맥에 'AI 직원 사무실'을 세우는 순서예요.
> 어려운 부분은 **Claude에게 맡기시면 돼요.** 사람이 직접 하실 일과 Claude에게 시킬 일을 나눠 적었어요.

---

|---|---|
| **맥** 한 대 (늘 켜 둘 것) | 사무실 프로그램이 맥에서 돌아요. 윈도우는 아직 안 돼요 |

## 1. 사람이 하실 일

1. 이 zip을 풀어서 `ai-office` 폴더를 홈 폴더(예: `/Users/내이름/ai-office`)에 둬요. 바탕화면·문서 폴더는 피해요. 맥 보안 때문에 늘 켜 두는 서비스가 그 폴더를 못 열 수 있어요.
2. 맥에 **Claude 앱**을 설치하고 로그인해요. 쓸 커넥터(헤이젠·힉스필드·캔바·구글 캘린더)를 Claude 앱 설정에서 연결해요.
3. Claude 앱의 **Code 탭**에서 `ai-office` 폴더를 열고 이렇게 말해요.
   > "이 폴더의 `처음부터_세우기_안내.md`를 읽고, 2장대로 내 사무실을 세워 줘."
4. Claude가 묻는 것에 답해요: 회사 이름, 나를 부를 호칭, 접속 비밀번호, 헤이젠 아바타·목소리 등
5. 다 되면 바탕화면의 사무실 아이콘을 눌러 열어요.

## 2. Claude가 할 일 (Claude에게)

1. **준비물 확인**: `python3`(맥 기본 3.9면 충분), `git`, `claude` 명령, `ffmpeg`(없으면 `brew install ffmpeg`), Xcode 명령줄 도구(`xcode-select --install`).
2. **맥 도구 만들기**
   - `swiftc -O tools/avatar_cutout.swift -o tools/avatar_cutout` (아바타만 오려 슬라이드 위에 붙일 때 씀)
   - `tools/pdf_to_png.swift`는 사무실이 필요할 때 알아서 써요.
3. **설정 파일**: `설정_예시_settings.example.json`을 `data/settings.json`으로 복사하고 채워요.
   - `passcode`: 접속 비밀번호. 또는 `python3 tools/set_passcode.py`로 정해요.
   - `remote`: 휴대폰·다른 컴퓨터로 들어올 거면 `true`, 아니면 `false` (true면 비밀번호가 꼭 있어야 켜져요)
   - `heygen.avatar_id`·`voice_id`(+이름): 헤이젠 도구로 목록을 보여 드리고 고르게 해요. ⚠ 헤이젠 새 목소리 엔진은 **예전 목소리를 거절**할 수 있어요(400 "not compatible"). 그러면 헤이젠에서 새 '즉시 복제' 목소리를 만들어 그 번호를 써요.
   - `heygen.voice_backup`(선택): 헤이젠 목소리가 막힐 때 힉스필드로 대신 만들 기준 목소리. 내 목소리 60~90초 mp3를 힉스필드에 올리고 받은 media 번호를 `ref_media`에 넣어요. 비워 두면 대비 길을 쓰지 않아요.
   - `input_dirs`: 내 원본 자료 폴더. 직원은 여기를 **읽기만** 해요.
   - `auto_approve`: 기획실장 자동 승인 범위(크레딧 한도 기본 700).
4. **회사 이름·호칭 바꾸기** (원하면)
   - `app/roster.json`의 `"company"`, `app/web/index.html`·`manifest.json`의 사무실 이름.
   - 직원 지시문은 사용자를 "교수님"으로 불러요(`app/prompts.py`, `app/engine.py`). 다른 호칭이면 바꿔요.
   - 바꾼 뒤 그림을 다시 만들어요: `python3 -X utf8 tools/build_scene.py && python3 -X utf8 tools/build_scene2.py && python3 -X utf8 tools/build_scene3.py`
5. **연습 모드로 먼저 켜 보기**: `OFFICE_FAKE=1 python3 -X utf8 app/server.py` → `http://127.0.0.1:8840`. 가짜 직원으로 흐름만 확인하고 꺼요(크레딧 안 씀).
6. **커넥터 확인**: `claude -p` 안에서 헤이젠(·힉스필드·캔바·구글 캘린더) 도구가 보이는지 확인해요. 안 보이면 사용자에게 Claude 앱에서 연결해 달라고 해요.
7. **늘 켜 두기**: `~/Library/LaunchAgents/kr.aioffice.office.plist`로 launchd 서비스를 만들어요(바탕화면 아이콘이 이 이름을 찾아요). `caffeinate -i -s /usr/bin/python3 -X utf8 {폴더}/app/server.py`, WorkingDirectory는 폴더, RunAtLoad·KeepAlive 켜기. `launchctl bootstrap gui/$(id -u) …`로 등록.
   - 다시 켜기: `launchctl kickstart -k gui/$(id -u)/kr.aioffice.office` (일하는 중인 단계는 처음부터 다시 하니, 쉬는 틈에)
   - ⚠ 폴더 접근은 꼭 서비스로 켠 상태에서 시험해요. 터미널에서는 되는데 서비스에서는 안 될 때가 있어요.
8. **바탕화면 아이콘**: `python3 tools/make_app.py`
9. **(선택) 무료 영상 도구**: `brew install whisper-cpp auto-editor manim`, Whisper 모델(`ggml-large-v3-turbo-q5_0.bin`, 약 550MB)을 `tools/models/`에 받아 둬요. Remotion 틀은 `cd tools/remotion_template && npm install`.
10. **(선택) 휴대폰·윈도우에서 들어오기**: Tailscale 설치, 필요하면 `tailscale funnel`을 8840에 연결. 다른 컴퓨터에 사무실을 하나 더 켜지 말아요(일 목록이 갈라져요).
11. **(선택) 구글 드라이브**: 드라이브 앱의 '내 Mac' 폴더 동기화에 `최종본_final` 하나만 추가해요. 맥 보안 설정은 바꾸지 않아요.
12. **(선택) 카톡으로 아침 보고 받기**: 비서 아침 보고를 카톡 '나와의 채팅'으로 받아요. 사용자가 developers.kakao.com에서 앱을 만들고(카카오 로그인 켜기·Redirect URI 등록·동의항목 '카카오톡 메시지 전송' 켜기) REST API 키를 준비한 뒤, 사용자 터미널에서 `python3 -X utf8 tools/kakao_setup.py`를 실행해요(카카오 로그인은 사용자가 직접). 로그인은 약 두 달마다 다시 해요. 키는 `data/kakao.json`에만 저장돼요.
13. **(선택) 기획실장 배경지식**: `data/knowledge/기획실장_배경지식.md`에 내 이력·하는 일을 짧게 적으면 기획실장이 계획마다 읽어요.
14. **설계서**: `설계서_design.md`를 읽고, 내 사무실에 맞게 고쳐 가며 써요. 기능이 바뀌면 같은 날 설계서도 고쳐요.

## 4. 꼭 지킬 것

- `data/settings.json`(비밀번호·아바타·목소리 번호)과 `data/` 폴더는 **남에게 주거나 인터넷에 올리지 않아요.**
- 돈이 드는 일(헤이젠·힉스필드 크레딧 등)은 결재함에서 확인한 뒤에만 해요.
- 원본 자료는 직원이 고치지 않아요. 결과물은 늘 `산출물_outputs/`와 `최종본_final/`에 따로 생겨요.
- 헤이젠 목소리를 한꺼번에 너무 많이 부르면 계정이 막힐 수 있어요. 사무실은 1분에 15쪽까지만 불러요.
